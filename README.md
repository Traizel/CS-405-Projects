# CS 405 — Secure Coding

This repository contains my projects and coursework from CS 405: Secure Coding at Southern New Hampshire University, completed as part of my bachelor’s degree studies in Computer Science with a Software Engineering concentration.

The coursework explores common software vulnerabilities and approaches to building more secure applications. Topics include buffer overflows, numeric overflows, exception handling, encryption, SQL injection, and static analysis.

Alongside programming exercises, this repository includes security policy documentation, a project presentation script, and a portfolio reflection. Together, these materials document my study of secure development practices and the role of security throughout the software development lifecycle.
